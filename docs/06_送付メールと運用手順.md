# 候補者への送付と回収 ― 運用手順

## 1. 全体の流れ

1. 採用担当者が `exam/営業職適性検査_受験用.html` を候補者にメール添付で送る
2. 候補者がファイルをダウンロードし、ブラウザで開いて受検する（オフラインでも動作する）
3. 受検終了後、候補者の画面に「回答ファイルを保存する」ボタンが出る。
   `適性検査回答_氏名_YYYYMMDD.txt` が保存される
4. 候補者がその .txt を返信メールに添付して返送する
5. 採用担当者が `exam/営業職適性検査_採点ツール.html` をブラウザで開き、
   受け取った .txt を読み込む。採点・尺度算出・重点確認事項の判定が自動で行われる
6. CSVを書き出して選考記録に残し、`docs/05_評価判定ガイド.md` に沿って面接官へ申し送る

## 2. 送付時の注意

- **添付するのは受験用HTMLのみ。** 採点ツール、`docs/03`、`docs/04`、`web/index.html` は
  解答キーを含むため、候補者には決して送らない。
- 受験用HTMLは1ファイルで完結しており、外部への通信は一切行わない。オフラインでも受検できる。
- 回答ファイルは **.txt** で書き出される。HTMLではなくテキストにしているのは、
  HTML添付が受信側のメールゲートウェイで隔離・削除されることがあるため。
- 候補者の環境でファイル保存ができない場合に備え、受検終了画面に
  「本文をコピーする」ボタンがある。メール本文に貼り付けて返送してもらっても採点できる。

## 3. 受検環境について候補者に伝えること

- 対応ブラウザ：Chrome / Edge / Firefox / Safari の最新版
- 所要時間：約60分。第1〜4部は制限時間があり、時間になると自動的に次の部へ進む
- 中断した場合、同じブラウザで開き直せば途中から再開できる。ただし**制限時間は中断中も進む**（期限を
  絶対時刻で保持しているため）。長時間の中断があった部は、再開時に終了扱いとなり次の部へ進む。
  再読み込みでは時間が戻らない。再読み込みの回数は回答ファイルに記録される
- 電卓は使用不可。計算用の紙と筆記用具を用意してもらう

## 4. 送付メールの文面

受検案内・リマインド・受領確認・トラブル時の返信の文面は
[07_候補者向け案内メール.md](07_候補者向け案内メール.md) にまとめてあります。

受検ファイルはHTMLです。**HTML添付は受信側のメールゲートウェイで隔離・削除されることがある**ため、
自社の共有ドライブに置いてダウンロードリンクを送る方法を推奨します。

## 5. 無監督で送付する場合の限界

リンクやファイルを送って各自の都合で受検してもらう方式では、次を担保できない。

- **本人が受検したかどうか**（替え玉受検を検出できない）
- **生成AIや第三者の助力を用いていないかどうか**

特に第1〜3部（言語・数的・論理）と第4部SJTは、問題文を生成AIに渡せば高得点が出る。
したがって**無監督で実施する場合、段階評価を合否判定の根拠として用いてはならない。**
面接での深掘り論点の抽出に用途を限定すること。

段階評価を選考材料として使いたい場合は、次のいずれかを取る。

- 面接と同日に、会場またはオンライン（カメラ＋画面共有）で監督付きで実施する
- 一次は無監督（参考情報）とし、最終選考の前に監督付きで本番を実施する

なお、回答ファイルには各部の所要時間・時間切れの有無・再読み込み回数が記録される。
不自然に短い所要時間や多数の再読み込みは、採点ツールの「受検ログ」で確認できる。
不正の証明にはならないが、面接で確認すべき候補者を見つける手がかりにはなる。

## 6. 問題の流出について

無監督で配布すれば、問題は早晩流出する前提で運用すること。
`tools/exam_data.py` を編集して `python3 tools/build_exam.py` を実行すれば、
受験用と採点ツールの両方が同時に更新される。年1回以上の設問差し替えを推奨する。
