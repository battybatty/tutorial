# Expert Partners Marketing 30秒動画CM

`https://expertpartners.jp/marketing/business/`（企業向けページ）の訴求内容をもとに制作した、
音声付き30秒のWeb動画CMです。

- 納品物: `build/ep_marketing_cm_30s_1080p.mp4`
- 仕様: 1920×1080 / 30fps / H.264 (High) / AAC 48kHz ステレオ / 30.00秒 / 約8MB
- 音声: ナレーション（日本語音声合成）＋オリジナルBGM＋効果音。すべて本リポジトリ内で生成しており、
  外部の音源・フォント素材のライセンス問題はありません（フォントはIPAゴシック / DejaVu Sans）。

## 訴求内容の根拠

制作時点でこの実行環境から `expertpartners.jp` へ直接アクセスできなかったため、
公開情報（サービス公式ページのタイトル、運営元のプレスリリース等）で確認できた事実のみを使用しています。

- サービス名 / 位置づけ: フリーランスマーケター特化のエージェントサービス（2023年4月提供開始）
- 登録者数: 2025年8月時点で10,000人突破
- 提供領域: マーケティングコンサル、広告運用、SEOディレクション、アフィリエイト、マーケアシスタント等
- 運営: 株式会社TWOSTONE&Sons グループ

料金や提案スピードなど、裏付けの取れなかった数値は意図的に入れていません。

## 制作フロー / 再生成

```bash
./build.sh
```

| ファイル | 役割 |
|---|---|
| `timeline.py` | シーン境界・ナレーション尺などのタイムライン定義（映像と音声で共有） |
| `narration.py` | 日本語音声合成でナレーションを生成（話速・軽いEQ/コンプ処理込み） |
| `bgm.py` | BGM（120BPM・15小節）と効果音（ライザー／インパクト／スイープ／チャイム）をnumpyで合成 |
| `mix.py` | ナレーションの包絡でBGMをダッキングしてミックス |
| `render.py` | 900フレームを描画し、ffmpegへrawvideoで流し込んでH.264/AACに変換 |

### 依存

```bash
pip install pyopenjtalk-plus pillow numpy imageio-ffmpeg
```

日本語フォント（IPAゴシック: `fonts-ipafont-gothic`）が必要です。

## 差し替えのポイント

- ブランドカラー: `render.py` 冒頭の `EMER` / `BLUE` / `WARN` を公式カラーに変更
- ロゴ: 現在はテキスト組み。公式ロゴ画像があれば `logo_lockup()` を画像貼り付けに差し替え
- ナレーション: `narration.py` の `LINES`（表示テロップ・読み・話速）を編集
- 縦型（9:16 / 1:1）: `timeline.py` の `W`,`H` と各シーンの座標を調整すれば別アスペクトも生成可能
