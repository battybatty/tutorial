# Bar "IYOIIYO" — ポーカートーナメント ブラインド計算機

`poker-blind-calculator.html` を**ダウンロードしてダブルクリックするだけ**で動きます。
インターネット接続・インストール・ビルドは一切不要（外部ファイル参照ゼロの単一HTML）。

## 使い方

1. **手元のチップ** … 額面・総枚数・色を入力（種類は追加／削除できます）
2. **トーナメント条件** … 参加人数と想定の所要時間を入力
3. 「**ブラインド表を作成**」を押すと、ストラクチャーが自動生成されます

「1人あたり」の枚数は自動配分されますが、手で書き換えることもできます。
設定はブラウザに保存され、次に開いたときに復元されます。

## 自動計算の考え方

| 項目 | ロジック |
|---|---|
| スターティングスタック | 小さい額面から順に配分。ある額面より下の合計より大きすぎるチップは配らず、途中のカラーアップ用に温存する。最後に合計がキリのいい数字になるよう最小額面で微調整 |
| 開始ブラインド | 開始スタックが目安BB数（既定75BB）になる値。手持ちの最小額面で支払える倍数に丸める |
| 1レベルの長さ | 想定時間・休憩から逆算し、ブラインド上昇率が ×1.4 前後に収まる長さを 6〜40分から自動選択 |
| ブラインドの上がり方 | 開始BB → 最終BB（総チップ ÷ 15）まで等比数列で上昇。各レベルは「その時点で場に残っている最小額面」で支払える値に丸める |
| アンテ | 全体の1/4を過ぎたレベルから。BBアンテ／全員アンテ／なしを選択可 |
| カラーアップ | ブラインドに対して小さくなりすぎた額面を、回収すべきレベルとともに提示 |
| 平均スタック | 各レベル開始時点の推定残り人数から算出。10BBを切るあたりが決着ゾーン |

想定時間に対してチップが多すぎる／少なすぎる場合は、警告と調整方法を表示します。

## その他の機能

- **トーナメントクロック** … カウントダウン、レベル自動送り、休憩、レベル切替時のブザー（Web Audio）
  - **全画面表示**に対応。ボタン・クロックのダブルクリック・`F` キーのいずれでも切り替えられます
  - 全画面中は時計が画面いっぱいに拡大し、経過時間・平均スタック・推定残り人数も表示。操作ボタンは3秒で自動的に消え、マウスを動かすと再表示されます
  - キーボード：`Space` 開始／一時停止、`←` `→` レベル送り、`Esc` 全画面終了
  - 対応環境では画面のスリープも抑止します（Screen Wake Lock）
- **参加者・スタック状況** … 進行中に人数を増減させながら、以下をリアルタイム表示
  - **残り人数 / エントリー数** … 「−」「＋」で脱落・取り消し、「＋エントリー」でリバイやレイトレジを追加
  - **アベレージスタック** … 総スタック ÷ 残り人数（現在のBB換算も表示。12BBを切ると赤字）
  - **総スタック** … エントリー数 × 開始スタック
  - 全画面表示中もこの3つが常に見え、`−` `+` キーとボタンで操作できます
  - 人数はブラウザに保存されるため、進行中にリロードしても失われません
- **CSVで保存** / **印刷・PDF出力**（印刷用レイアウトあり）
- **ロゴの書き出し** … ベクター（SVG）で描き起こしてあるので、SVG保存または 4000px PNG 保存で好きな解像度に高画質出力できます
