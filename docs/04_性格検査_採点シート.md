# 第5部　性格・行動特性 ― 採点シート（採点者用・社外秘）

## 1. 採点手順

1. **逆転項目**（下表で「逆」と記した項目）は、回答値を **6 − 回答値** に変換する
   （5→1、4→2、3→3、2→4、1→5）。
2. 尺度ごとに変換後の値を合計し、**素点**を出す。
3. 素点を項目数で割り、**尺度平均（1.0〜5.0）** を算出する。小数第2位を四捨五入。
4. 尺度平均を「5. 段階換算」の表で5段階に換算する。
5. **L尺度（回答態度）を最初に確認する。** L尺度が高い場合、他尺度の解釈を保留する。

## 4. L尺度（回答態度）の判定 ― 先に確認すること

L尺度の項目は「一度もない」という、現実にはほぼ起こりえない内容で構成されている。
これらに高く回答するほど、**自分を良く見せようとする傾向（社会的望ましさ）** が強いと考えられる。

| L尺度平均 | 判定 | 対応 |
|---|---|---|
| 4.2 以上 | 回答の歪みが強く疑われる | **他の尺度の数値は参考程度にとどめる。** 面接では自己申告ではなく、具体的な行動事実（いつ・何を・どうしたか）で確認する |
| 3.5 〜 4.1 | やや自己呈示が強い | 高得点尺度は割り引いて解釈する |
| 3.4 以下 | 標準的 | 通常どおり解釈してよい |

**注意**：L尺度が高いこと自体を不合格理由としない。採用選考という場面では自己呈示が強まるのが自然であり、
「面接で裏づけを取るべき」というシグナルとして用いる。

## 5. 段階換算

| 尺度平均 | 段階 | 目安 |
|---|---|---|
| 4.3 以上 | **5** | 非常に高い |
| 3.8 〜 4.2 | **4** | 高い |
| 3.2 〜 3.7 | **3** | 標準 |
| 2.6 〜 3.1 | **2** | やや低い |
| 2.5 以下 | **1** | 低い |

> **この換算基準は暫定値である。** 自社の受験者データが100名分程度蓄積した時点で、
> 実際の分布（平均・標準偏差）に基づく基準に置き換えること。
> 蓄積前の段階では、段階の絶対値よりも **同一応募者内での尺度間の高低差（プロファイルの形）** を重視する。

## 6. 尺度の解釈

性格特性に優劣はない。**高い＝良い、低い＝悪い、ではなく、職務要件との適合を見る。**

### A　達成志向
数値目標に向かう推進力、未達への感度、自己成長への意欲。

- **高い（4〜5）**：目標必達の姿勢が強い。新規開拓・数値管理の厳しい環境で力を発揮しやすい。／*留意*：短期の数字を優先し、顧客の利益や手続きを軽視していないか、D尺度およびSJT第5・6問と併せて確認する。
- **低い（1〜2）**：数値プレッシャーの強い環境では消耗しやすい可能性。／既存顧客の深耕やカスタマーサクセス寄りの役割との適合を検討する。

### B　対人影響力
関係構築の速さ、説得力、聴く力を含む対人スキルの自己認識。

- **高い（4〜5）**：初期接点の構築や折衝で強みを発揮しやすい。／*留意*：話す力に偏っていないか、項目33（傾聴）の回答を個別に確認する。
- **低い（1〜2）**：新規開拓型よりも、専門知識で信頼を得る技術営業・インサイドセールス型との適合を検討する。

### C　ストレス耐性
拒絶・失敗・想定外からの回復力と、感情の安定。

- **高い（4〜5）**：断られることの多い営業活動を継続しやすい。
- **低い（1〜2）**：**単独での不合格理由としない。** 拒絶頻度の高い職務では立ち上がり支援や同行体制が必要かどうかの検討材料とする。健康状態を推知する目的では一切用いない。

### D　誠実性・コンプライアンス
規程順守、正直さ、機密の取り扱い。**営業職において最も重視すべき尺度。**

- **高い（4〜5）**：長期の信頼関係を築きやすい。／*留意*：項目48が特に高い場合、柔軟性を欠いていないか確認する。
- **低い（1〜2）**：**要確認事項**。SJT第3・5・6・10問の得点と必ず併せて見る。両方が低い場合は、面接で具体的な過去の判断事例を確認したうえで慎重に判断する。

### E　自律・行動力
指示待ちにならず、自ら課題を見つけて動く傾向。

- **高い（4〜5）**：裁量の大きい環境、少人数組織で機能しやすい。／*留意*：報告・相談の頻度が十分かをSJT第1・8問と併せて確認する。
- **低い（1〜2）**：手順が確立した環境では問題になりにくい。育成前提の新卒採用では、必ずしもマイナス評価としない。

### F　協調・チーム貢献
情報共有、他部門連携、チーム成果への意識。

- **高い（4〜5）**：分業型・アカウント制の営業組織で機能しやすい。
- **低い（1〜2）**：個人完結型の営業では問題になりにくいが、当社の営業体制が分業型である場合は適合を検討する。
