# 営業職 採用適性検査

営業職（新卒・中途共通）の採用選考で用いる適性検査の一式です。
問題冊子・解答用紙・採点基準・評価判定ガイドで構成されています。

## 検査の構成

| 部 | 領域 | 問題数 | 時間 | 配点 |
|---|---|---|---|---|
| 第1部 | 言語能力（語彙・語法・読解） | 10問 | 10分 | 20点 |
| 第2部 | 数的処理（営業実務型） | 12問 | 15分 | 24点 |
| 第3部 | 論理推理 | 8問 | 10分 | 16点 |
| 第4部 | 状況判断テスト（SJT） | 10問 | 15分 | 30点 |
| 第5部 | 性格・行動特性 | 56項目 | 10分 | プロファイル |
| 合計 | | 40問＋56項目 | 約60分 | 90点 |

### 測定する性格尺度

達成志向 / 対人影響力 / ストレス耐性 / 誠実性・コンプライアンス / 自律・行動力 /
協調・チーム貢献 の6尺度、および回答の歪みを検出するライスケール。

## 設計上の方針

- **第2部は電卓なしで解ける水準**に設計。値引き・粗利・達成率・確率など営業実務で扱う数値に限定。
- **正解の選択肢位置を各記号に均等配分**し、記号の偏りからの推測を防止。
- **SJTは正誤ではなく0〜3点の重み付け採点**とし、選択肢間の優劣を段階的に評価。
- **性格検査には逆転項目7項目とライスケール5項目**を混在させ、回答の一貫性と自己呈示傾向を検出。

## 運用上の注意

- **本検査は選考の一資料であり、単独で合否を決定するものではありません。**
- 段階評価の基準は暫定値です。受験者データの蓄積後、実際の得点分布と入社後成績との相関に基づいて
  見直してください（詳細は [docs/05_評価判定ガイド.md](docs/05_評価判定ガイド.md) 参照）。
- 職業安定法および厚生労働省「公正な採用選考の基本」に沿い、本籍・思想信条・家庭環境等を
  問う設問は含めていません。運用時の遵守事項は [docs/00_実施要領.md](docs/00_実施要領.md) を参照してください。
- **docs/03 および docs/04 は解答キーを含みます。** 応募者に開示されない管理を徹底してください。
