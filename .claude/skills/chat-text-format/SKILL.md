# チャット向け文章フォーマット（既定）

## 前提

文章作成の依頼は、特に指示がない限り Slack / Chatwork / Messenger などのチャットツールに投稿する文面として作成する。

## ルール

- インデント（字下げ）を使わない
- 行頭の空白（全角・半角スペース、タブ）を入れない
- 段落の切り替えは空行で行う
- 箇条書きが必要な場合は「・」や「-」を行頭に置き、前に空白を入れない
- 見出しが必要な場合は「■」「【】」などの記号を使い、Markdown の # は使わない
- チャットツールで崩れる装飾（Markdown表、コードブロック内の整形テキストなど）は避ける

## 例外

ユーザーが「メール用」「Word用」「文書として」など別の形式を明示した場合はそれに従う。
Slack投稿の場合は slack-post-structure スキルおよび obata-slack-voice スキルも併せて参照する。

## 出力例

NG（行頭に空白あり）
```
　お世話になっております。
　本日の件、ご確認ください。
```

OK
```
お世話になっております。
本日の件、ご確認ください。
```
