# チャットログ

Claude Code とのセッションの記録を、1 セッション 1 ファイルで残す。

## ルール

- ファイル名: `YYYY-MM-DD-<短い英語スラッグ>.md`
- 形式は `TEMPLATE.md` に従う。生の転記（JSONL）はコミットしない。
- 依頼内容・やったこと・決めたこと・次にやることを書く。ツール出力の貼り付けは最小限にする。
- 社内固有の ID、個人名、メールアドレス、認証情報は書かない（public リポジトリのため）。
- セッション中に分かった継続すべき事実は `docs/memory/MEMORY.md` にも反映する。
