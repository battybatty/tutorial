# Slack投稿の構造ルール

## 原則
- チャンネルに流すのは **親メッセージ1〜2行のみ**。詳細はすべてスレッドへ。
- 短文・簡潔・視認性優先。読む側のコストを最小にする。
- 文面自体は chat-text-format スキルのルール（インデントなし、行頭空白なし）に従う。

## 親メッセージの型
```
@宛先 cc @関係者
:絵文字: *【種別】タイトル（目安○分）*
```
- 種別: 【依頼】【共有】【相談】【確認】など
- 目安時間は作業依頼のときだけ付ける
- 絵文字は内容に合わせて1つ（:memo: :warning: :white_check_mark: など）

## スレッド（1件目の返信）に入れるもの
- 背景・目的（1〜2文）
- リンク（Doc / Asana / 資料）
- 構成・手順・担当（箇条書き）
- 相手別の依頼事項（「Aさん・Bさん：〜」）
- 期限

## 例

親:
```
@担当者 cc @関係者A @関係者B
:memo: *【依頼】引継ぎシートの記入（目安30分）*
```
スレッド: 背景 → Docリンク → 構成（項目と担当の一覧）→ 関係者への確認依頼 → 期限
