# 候補者向け案内メール文面

そのままコピーして使えます。【　】は送信前に必ず差し替えてください。

## 配布方法について

受検ファイルは HTML です。**HTML添付は受信側のメールゲートウェイで隔離・削除されることがある**ため、
自社の共有ドライブ（Google ドライブ等）に置いてダウンロードリンクを送る方法を推奨します。
下の本文は「リンク配布版」を基本とし、添付で送る場合の差し替え文も併記しています。

Google ドライブに置く場合は、ファイルを「リンクを知っている全員が閲覧可」に設定してください。
HTMLはドライブ上ではプレビューできませんが、候補者はダウンロードボタンから取得できます。

## 1. 受検案内メール（本送付）

**件名**

```
【株式会社〇〇】適性検査ご受検のお願い（〇月〇日（〇）〇時まで）
```

**本文**

```
【候補者氏名】 様

お世話になっております。
株式会社〇〇 人事部の【担当者名】です。

このたびは弊社営業職の求人にご応募いただき、誠にありがとうございます。
選考の一環として、適性検査のご受検をお願いいたします。

本検査は選考の判断材料の一つとしてお伺いするものであり、この結果のみで
合否を決定することはございません。ご入社後の配属や育成計画を考えるうえでも
活用させていただきます。

■ 受検方法

1. 下記リンクからファイルをダウンロードし、パソコンに保存してください
   【ダウンロードリンク】

2. 保存した「営業職適性検査_受験用.html」をダブルクリックし、
   ブラウザで開いてください

3. 画面の案内に従ってお進みください

インターネットに接続していない状態でもご受検いただけます。

■ 所要時間

約60分（全5部）

第1部から第4部までは部ごとに制限時間があり、時間になると自動的に次の部へ
進みます。一度先に進むと、前の部に戻ることはできません。

制限時間は中断している間も進みます。長時間の中断があった部は、その時点で
終了となりますので、まとまったお時間を確保できるときにお願いいたします。

なお、通信の切断や誤操作に備え、同じパソコンの同じブラウザで開き直せば、
中断した箇所から再開できるようになっています。

■ ご用意いただくもの

・パソコン（Google Chrome、Microsoft Edge、Firefox、Safari の最新版を推奨）
・計算用の紙と筆記用具

第2部では電卓および計算機能のある機器はご使用いただけません。
すべて筆算で解ける内容です。

■ ご回答の返送方法

受検が終わりますと、画面に「回答ファイルを保存する」ボタンが表示されます。
保存された「適性検査回答_お名前_日付.txt」を、本メールへのご返信に添付して
お送りください。

ファイルの保存がうまくいかない場合は、同じ画面にある「本文をコピーする」を
押していただき、メール本文に貼り付けてお送りいただいても差し支えありません。

■ 返送期限

【〇月〇日（〇）〇時】

■ ご回答にあたってのお願い

生成AI（ChatGPT等）、検索、書籍、他の方のお力添えを用いず、
【候補者氏名】様ご自身のお力のみでご回答ください。

本検査の結果は、ご入社後にどのような業務からお任せするか、どのような支援を
ご用意すべきかを考えるためにも用います。実際のお力と異なる結果は、
【候補者氏名】様ご自身にとっても望ましいものになりません。

分からない設問があっても問題ございません。誤答による減点はございませんので、
いずれかをお選びのうえお進みください。

■ 取得する情報の取り扱いについて

ご入力いただくお名前・メールアドレスおよびご回答内容は、採用選考の判断材料と
してのみ利用いたします。選考終了後1年を目安に、復元できない方法で廃棄いたします。
第三者へ提供することはございません。

■ 受検時の配慮について

体調、障害、その他のご事情により、時間の延長や別の形式でのご受検など、
配慮が必要な場合は、受検前に下記までお知らせください。
お申し出の有無やその内容が、選考の評価に影響することは一切ございません。

ご不明な点がございましたら、お気軽にお問い合わせください。
【候補者氏名】様とお会いできますことを楽しみにしております。

────────────────────────
株式会社〇〇 人事部
【担当者名】
TEL：【電話番号】
Email：【メールアドレス】
────────────────────────
```

### 添付で送る場合の差し替え

「■ 受検方法」の1と2を、次に置き換えてください。

```
1. 添付ファイル「営業職適性検査_受験用.html」をパソコンに保存してください

2. 保存したファイルをダブルクリックし、ブラウザで開いてください
```

## 4. トラブル時の返信（ファイルが開けない・保存できない）

**本文**

```
【候補者氏名】 様

お世話になっております。株式会社〇〇 人事部の【担当者名】です。

ご連絡いただきありがとうございます。ご不便をおかけし申し訳ございません。
下記をお試しいただけますでしょうか。

■ ファイルが開けない場合

ダウンロードしたファイルを右クリックし、「プログラムから開く」から
Google Chrome、Microsoft Edge、Firefox、Safari のいずれかをお選びください。

スマートフォンやタブレットでは正しく動作しない場合がございます。
恐れ入りますが、パソコンでのご受検をお願いいたします。

■ 回答ファイルが保存できない場合

受検終了画面の「本文をコピーする」ボタンを押していただくと、回答の内容が
コピーされます。そのままメール本文に貼り付けてご返送ください。
ファイルの添付は不要です。

■ 途中で中断してしまった場合

同じパソコンの同じブラウザで受検用ファイルを開き直していただくと、
中断した箇所から再開できます。ただし制限時間は中断中も進んでおりますので、
長時間経過している場合は、その部が終了した状態から再開となります。

再開できない場合や、最初からやり直したい場合は、その旨ご連絡ください。
状況をうかがったうえで対応いたします。

上記で解決しない場合は、お使いのパソコンとブラウザ（Windows / Mac、
Chrome / Edge など）をお知らせいただけますと幸いです。

────────────────────────
株式会社〇〇 人事部
【担当者名】
TEL：【電話番号】
Email：【メールアドレス】
────────────────────────
```

## 送信前チェックリスト

・【　】をすべて差し替えたか
・添付またはリンクが「受験用」であることを確認したか
　（採点ツール、docs/03、docs/04、web/index.html は解答キーを含むため絶対に送らない）
・リンクの共有設定が「リンクを知っている全員が閲覧可」になっているか
・返送期限が具体的な日時になっているか
・問い合わせ先が実在の窓口になっているか
・宛名の敬称、社名の表記に誤りがないか
